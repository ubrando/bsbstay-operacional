# Módulo Operacional

Kanban de limpezas, tarefas, atribuição de camareiras, controle de tempo.

Rotas relacionadas (em `src/routes/`, seguindo a convenção file-based do
TanStack Router): `app.kanban.tsx`, `app.tarefas.*.tsx`, `app.unidades.*.tsx`,
`app.usuarios.tsx`, `app.minhas-tarefas.tsx`, `app.alertas.tsx`,
`app.metricas.tsx`, `app.liberacao.tsx`.

Tabelas: `tarefas`, `tarefa_camareiras`, `tempo_registros`, `solicitacoes`,
`liberacoes`, `vistoria_demandas`.

Ainda pendente de implementação nesta fase — ver `README.md` na raiz,
seção Status.
